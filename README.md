# Airline Simulator · 航空运行控制中心（AOCC）

面向 **Airline Simulator** 玩家的第三方航空公司管理工具。连接你自己的游戏账号后，可以在本地工作台查看航班、机队、航线和经营数据。内置演示无需登录。

## 能做什么

| 功能 | 用法 |
| --- | --- |
| 航班监控 | 在地图和运行看板查看即将起飞、在途和即将到达的航班，按机场、机型、注册号筛选，并区分自营和共享航班。 |
| 机队与客舱 | 查看飞机任务、单机七天时间轴与航迹回放，以及各舱等的座位数、座距和交互式客舱平面图。 |
| 排班助手 | 查找现有航班的空缺运营日，评估开航和增班方案，检查客舱产品一致性、任务重叠、机场衔接和短过站。 |
| 航线与班表 | 查看各基地、目的地和代码共享协议。每周班表支持机场当地时间和 UTC，可下载 HTML、CSV 或打印为 PDF。 |
| 经营分析 | 比较航线周计划利润、计划旅客和运力，查看本机保留的历史，并导出单文件分析包。 |

地图位置按游戏时钟、班表和大圆航迹推算。周旅客和周利润采用游戏的计划数据。排班助手给出方案，实际调整在游戏内完成。

## 快速开始

**Windows 桌面版**需要 Node.js 24 或更新版本。下载或克隆本仓库，在项目目录双击 `Start AOCC.cmd`。首次启动会安装依赖并构建应用，需要联网。双击 `Stop AOCC.cmd` 停止后台服务。

也可以在项目目录运行：

```powershell
npm ci
npm run build
npm start
```

启动后访问 [本机工作台](http://127.0.0.1:3010)。

- **先试用**。进入「数据连接」，点击「探索演示场景」。
- **连接自己的航司**。在 Chrome 或 Edge 加载 `tools/session-bridge`，在游戏官方涂装编辑器登录，然后用一次性配对码连接本机工作台。单航司账号会自动匹配。多航司账号可在「高级手动接入」填写要同步的航空公司 ID。完整步骤见 [连接指南](docs/connection-guide.md)。
- **使用 Android 版**。从源码构建独立应用，再使用自己的游戏会话连接。步骤见 [Android 构建与连接说明](android/README.md)。

## 数据与运行

桌面端默认监听 `127.0.0.1:3010`，连接后默认每 60 秒同步一次。关闭网页后，后台服务仍会运行。可通过 `Register-AOCCStartup.ps1` 设置登录后自动启动，以 `Register-AOCCStartup.ps1 -Remove` 取消。

游戏业务数据以只读方式获取。SQLite 历史和加密会话保存在本机 `.data/`。官方浏览器和工具同时使用时，游戏刷新令牌轮换可能要求重新配对。游戏客户端或服务升级后，连接器可能需要更新。

`web/` 包含界面及班表逻辑，`server/` 包含连接器、同步和历史存储，`android/` 包含独立手机版源码。用 `npm run check` 验证桌面构建与测试。游戏原版图片可从本地 `public/game-assets/` 加载。
