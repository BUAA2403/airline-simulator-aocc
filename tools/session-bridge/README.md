# Airline Simulator AOCC 本地会话连接扩展

适用于 Windows 的 Chrome / Edge。扩展没有后台脚本和定时任务；只有点击「连接本机 AOCC」时才运行。

## 安装和连接

1. 在项目目录运行 `npm run dev`，打开 `http://127.0.0.1:3010`。
2. Chrome 打开 `chrome://extensions`，Edge 打开 `edge://extensions`，启用「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择本文件夹 `tools/session-bridge`，可将扩展固定到工具栏。
4. 在 AOCC 的数据连接界面获取一次性配对码。配对码 10 分钟内有效，成功后失效。
5. 自行打开 [官方涂装编辑器](https://livery.airline-simulator.com/)，使用游戏对应的 Google / Apple 账号登录。官方编辑器正常首次登录可能创建涂装编辑器档案；这是官方网站自身的行为。
6. 保持官方编辑器为当前标签页，打开扩展，填写 AOCC 配对码，点击「连接本机 AOCC」。
7. 看到成功消息后返回 AOCC，核对航空公司名称并等待首次同步。

扩展无需访问剪贴板；只有你自行复制、粘贴配对码。会话令牌不会显示，也无需复制令牌。

## 精确的数据路径

- 读取来源：当前主框架必须为 `https://livery.airline-simulator.com`，读取唯一 localStorage 键 `sb-auth-auth-token`。
- 发送目的地：固定为 `http://127.0.0.1:3010/api/session-bridge`。
- 请求内容：`{ pairingCode, session: { access_token, refresh_token } }`，丢弃用户资料、第三方提供商令牌及其他原始字段。
- 扩展不保存会话或配对码，没有后台自动读取、网络重试、遥测、日志或第三方脚本。
- 仅申请官方涂装编辑器、本机 AOCC 的主机权限，以及执行指定页面读取函数所需的 `scripting` 权限。
- AOCC 服务负责校验一次性配对码、验证会话身份及本地保存会话。游戏数据访问由 AOCC 服务的只读端点白名单约束。

这里使用既有官方登录会话，没有创建独立的只读令牌。不要将导出的会话、服务器密钥文件或浏览器档案放入代码仓库。

## 常见问题

**要求切换到官方标签页**：打开或切换至官方涂装编辑器，再点击浏览器工具栏的扩展。扩展不会自动开页或登录。

**找不到会话**：确认编辑器已登录，并且账号与游戏一致。扩展只识别官方当前采用的指定存储键和标准 Supabase 会话结构。

**配对码过期 / 已使用**：返回 AOCC 获取新配对码。连接超时可能发生在服务器完成接收后，先查看 AOCC 连接状态。

**无法连接本机**：确认服务运行在 `127.0.0.1:3010`。此扩展没有远程 AOCC 地址配置。

**会话失效**：在官方编辑器确认登录后重新连接。官方浏览器与本机服务共享刷新令牌时，令牌轮换可能导致重新连接；AOCC 不应循环重试失效令牌。

使用完成后，可以在浏览器扩展管理页面停用或移除此扩展。
