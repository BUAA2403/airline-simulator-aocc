# AOCC · 极地航行情报台

这轮设计以导航仪表、航空出版物和夜间航图为基础：石墨色背景、冰蓝航线、琥珀色飞机与重点标记，使用细分隔线与统一编号建立信息层级。主数据采用清晰的窄体数字，中英文标题与操作说明分别排版。

调度台使用连续仪表栏、航网主画面和运行简报组成首屏；无告警时，简报仍显示真实的近期离港任务。机队、客舱与经营分析沿用同一套统计、筛选与表格语言。航班详情使用与航程进度关联的航路图示；单机周排班保留表格、时间轴和航迹回放。发布班表保留适合打印的纸张视图。

代码入口为 `web/polar-design.css` 和 `web/identity.jsx`，已有的数据同步和业务口径保持原样。样式没有新增外部字体或图像服务依赖。系统尊重设备的减少动态效果设置。
