# 航班详情与客舱布局改版

## 客舱

参考新加坡航空官方 A350 座位图的舱等分区、排号与平面图层次，以及国泰官方 777 机队页的布局呈现方式，使用本地 SVG 重绘，不复制真实航司机型座位配置。轮廓为游戏客舱的示意，非工程图；座位总数、排数、分区与座椅产品继续使用游戏数据。

- https://www.singaporeair.com/saar5/pdf/OurFleet/A350-900-3classes-LongHaul.pdf
- https://www.cathaypacific.com/cx/en_CN/flying-with-us/aircraft-and-fleet/boeing-777/300.html

机身采用圆润前段、渐缩尾段，主翼和水平尾翼后掠，增加发动机进气口、翼面线条、驾驶舱风挡与舷窗。客舱平面图在航班详情、配置库及客舱弹窗复用，数量保持原始游戏口径。未虚构出口、厨房或洗手间位置。

## 四个视角

- 本次航班：选中执行任务的状态、进度、起降时刻、预计旅客与客座率、过站、客舱；坐标与分舱数据折叠显示。
- 航班号：当前航班号在全部飞机与同号经停航段上的周时刻、周航段数量与执飞机队。
- 航线：当前机场对双向的全部航班号、周航段、原生往返任务周计划利润、预计客座率与机队。
- 飞机：当前注册号的客舱、周航段、计划利用率、下一任务及每周排班。

全部视角基于最新快照重算；实时进度与倒计时按运行时钟推进。滚动多周发生项先按周计划去重，同一往返利润只计一次。单机统计先按飞机过滤，再生成周班表，避免相同时刻由多个飞机执行时误计其他飞机的班次。缺失经营数据保持未知。

## 验证

88 项测试通过，包含新增的航班号、双向航线与单机范围区分、跨周去重、经停同号统计、利润去重和删除计划后更新。生产构建通过。浏览器验证四个标签切换、计划航班跳转、客舱弹窗与座椅产品切换。

## 具体执飞机对应关系

每条时刻卡片保留逐架飞机的注册号、当地执飞星期、原生任务键和周航段数。相同机型与时刻仍合并展示，卡片内分别列出每架飞机的运营日；选中的执行任务标记“本次”。点击注册号按该飞机和任务键定位飞行中或最近后续执行，不回退到其他飞机。多周去重、返程当地跨日与缺失任务均有测试覆盖。CA319 实测：B-1161 周五，B-8421 周一、六，B-7916 周日；浏览器逐一核对注册号切换，点击 B-8421 显示计划中任务，点击 B-1161 返回飞行中任务。
