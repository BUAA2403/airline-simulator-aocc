# 多基地运行

基地列表直接来自游戏航空公司的 `hubAirports`，保存为快照 `airline.hubs`；`airline.hub` 保留首个基地，兼容旧快照。飞机所属基地来自其原生 `hubAirport`，保存为 `homeBase`，与当前位置分开。普通航线目的地、合作航司基地不会自动成为 当前航司的基地。

每次正常同步后，新增、移除基地都会自动反映到：

- 每周计划的基地筛选、基地／区域／目的地编排以及 HTML、CSV、打印。
- 运行看板的基地筛选、地图全部基地标记及逐基地放大入口。
- 航线网络的基地筛选和对应覆盖统计。
- 机队的所属基地、基地筛选及单机排班的基地时间。
- 单文件 AI 分析包的基地列表、单机所属基地和发布班表。

往返计划任一端是基地时从基地出发显示，经停全程与首段采用同一归组。全航网视图中，基地间计划优先按分配飞机的所属基地定向；无法确认时保留原生起点，同一任务只归入一个基地。筛选单个基地时，两端均是基地的航班改从所选基地出发显示，不增加任务或班次。自营与共享仍分开发布。基地排序跟随游戏列表，首个标为主基地，其余标为基地。

验证覆盖 PEK＋PVG、新增 CAN、基地撤销、反向计划、经停、基地间计划去重、旧格式兼容、导出及定时同步。无需维护固定的基地代码表。
