# 一键导出 AI 分析资料

在任意页面右上角点击 **导出 AI 分析包**，或在「数据连接」的数据工具中使用同名入口。系统会下载一个 `.md` 文件，无需解压或合并。

把这个文件上传给支持文件阅读的 AI，并告诉它：「请按照文件内的分析指引，对我的航空公司做全面分析，给出有数据依据的优化建议。」

文件包含最新已同步的机队与客舱、机场与区域、航线、每个航班计划的飞机分配、周班表、各舱票价及旅客预估、周计划利润、采集时运行态势，以及本机仍保留的历史采样和配置变化。文件开头提供统计口径与分析指引，后面附完整结构化数据。

每次导出读取当时的最新已同步快照；如需刚刚修改的游戏资料，可先点击「同步数据」，成功后再导出。文件记录采集时间、连接状态、历史覆盖和缺失项。历史只覆盖本机保留的采样，周计划预估与实际结算分别标识；未提供的数据不会补造。

导出不包含登录令牌、账户身份资料或同步日志，也不会自动上传至任何 AI 服务。

历史配置采用无损差量以减少文件大小：先以 `configuration` 为基础应用 `history.baseline.changes`，还原最早保留的配置，再依次应用 `configurationRevisions`。每个表中的 `added` / `updated` 是完整新记录，`removed` 是要移除的记录 ID。连续同值经营观测合并存储，但保留全部 `observedAt` 采样时刻。
