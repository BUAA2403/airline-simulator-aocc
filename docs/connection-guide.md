# 接入 Airline Simulator 的真实数据

AOCC 的真实数据连接来自你自己在官方涂装编辑器中的登录会话。游戏账号登录留在官方网站，本机系统不收集 Google / Apple 密码。

## 连接步骤

1. 启动本地 AOCC：在项目目录执行 `npm run dev`，访问 `http://127.0.0.1:3010`。
2. 按 [本地连接扩展说明](../tools/session-bridge/README.md) 在 Chrome 或 Edge 加载 `tools/session-bridge` 文件夹。
3. 在 AOCC 生成一次性配对码。配对码有效期 10 分钟，成功连接后失效。
4. 自行访问 [官方涂装编辑器](https://livery.airline-simulator.com/)，使用游戏账号登录。网站首次登录可能创建涂装编辑器档案，这是官方编辑器的正常初始化行为。
5. 保持该官方页面为当前标签页，点击浏览器工具栏的 AOCC 本地连接扩展，粘贴配对码并点击「连接本机 AOCC」。
6. 返回 AOCC 核对航空公司，查看同步状态和最后成功更新时间。若游戏账户管理多家航司，请打开「高级手动接入」，填写目标航空公司 ID，令牌栏留空以复用已配对的会话，再点击「更新并同步」。

扩展只在这次点击时读取官方页面唯一指定的 localStorage 会话键，将必要的两项会话字段直接发往本机端口。不会显示令牌，不读取其他网站，也不储存会话。

## 自动更新与重新连接

本机服务使用已验证的会话读取获准的航空公司数据，并按配置间隔更新。网页在两次服务器更新之间根据航班时刻计算位置，计算位置应与服务器返回的实测数据明确区分。

离线、接口错误或会话到期时，界面应保留最后成功的数据，并显示其时间和状态。会话无法正常刷新时，重新按上述步骤连接；不会通过网页登录密码自动登录。

保持 AOCC 服务和计算机运行，网页才可以持续收到更新。将窗口关闭与停止服务区分开来：关闭浏览器页面不应中断正在运行的本机服务。

## 数据边界

登录会话是现有官方会话，并非游戏单独签发的只读凭据；AOCC 在服务端限制游戏请求为已确认的读取接口和你的授权航空公司。扩展发给本机的会话仅供这一连接使用。

金额显示需保留游戏单位：官方 FAQ 说明所有游戏金额采用 K（千）。航班地图应区分时刻推算的位置与服务器提供的实时坐标，避免把预测当作实时观测。

目前未发现游戏官方面向第三方的通用数据 API 文档。本实现依据官方客户端已使用的接口建立连接；客户端或服务端升级后，数据适配器可能需要调整。连接研究记录见 [官方网页协议说明](../research/web/PROTOCOL-NOTES.md)。
