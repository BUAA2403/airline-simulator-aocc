# 目的地班表与经停航班

周班表按主基地到每一个可达目的地编排。PEK–ICN–NRT 会产生：

- PEK–ICN：实际第一航段及返程时刻。
- PEK–NRT：全程去返程各一行，标注经停 ICN。

多个经停点按相同规则生成每个基地起点的前缀行程，目的地分区沿用统一机场目录。普通直飞航班与经停航班按同一目的地分组。

`web/destination-services.mjs` 从原始班表和已核实的原生子航班关系生成发布视图。全程时刻使用同一飞机实际连续执飞的航段，离港采用第一段、到港采用最后一段，总耗时包括经停；运营日和跨日标记重新按所选当地时间或 UTC 计算。不同航班号会完整保留，机型切换和飞机分配也保留原始对应关系。

不会仅因两条航线首尾机场相接就判定经停，也不会跨飞机拼接。如果缺少后续航段，或该飞机中间执行了其他任务，则保留实际航段显示，不虚构全程航班。此模块只派生显示数据，不修改游戏班表。

网页、下载 HTML、CSV 和打印共用发布结果。每次同步收到新快照后重建，新增、调整时刻、删除经停关系均无需额外维护目的地清单。真实 CA1698/1699 的 PEK–ICN–NRT、CA6849/6850 的 PEK–BKK–SIN、CA872/873 的 PEK–HND–LAX、CA4357/4358 的 PEK–CAN–SYD 已核对；本次更新前后全航网每周班次均为 1482（核对时快照）。

验证：`node --test tests/destination-services.test.mjs`；完整检查：`npm run check`。
